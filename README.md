راه هنر - بسته Flutter برای ساخت APK

محتوا:
- رابط اصلی HTML/JavaScript در assets/web (داخل WebView اجرا می‌شود)
- پوسته Flutter و پل اعلان بومی اندروید
- درخواست مجوز اعلان در Android 13+ هنگام اجرای نخست
- زمان‌بندی اعلان‌ها با flutter_local_notifications
- ساعت سکوت و دسته‌بندی اعلان‌ها
- پنل برنامه‌ساز JSON، ویرایش فعالیت‌ها، نسخه‌بندی برنامه
- حذف کارت ظرفیت و مشغله امروز
- GitHub Actions برای ساخت APK رایگان

ساخت APK:
1) این پوشه را در یک مخزن GitHub با نام دلخواه بارگذاری کن.
2) در GitHub به Actions برو و workflow با نام Build Android APK را اجرا کن.
3) پس از اتمام موفق، از بخش Artifacts فایل rah-honar-release-apk را دریافت کن.
4) داخل ZIP، app-release.apk قرار دارد.

ساخت محلی:
Flutter SDK و Android SDK لازم است:
  flutter pub get
  flutter build apk --release

نکات مهم:
- این نسخه APK واقعی Flutter است، اما رابط فعلی HTML در WebView نمایش داده می‌شود تا امکانات نسخه موجود حفظ شوند؛ بازنویسی کامل UI به ویجت‌های Flutter انجام نشده است.
- برنامه به API پولی یا سرور اختصاصی نیاز ندارد. ارتباط ChatGPT همچنان با کپی پرامپت و واردکردن JSON دستی است.
- اعلان‌ها پس از اجازه کاربر فعال می‌شوند. اندروید 13 به بالا مجوز POST_NOTIFICATIONS می‌خواهد.
- زمان‌بندی فعلی از حالت inexact استفاده می‌کند تا به مجوز Exact Alarm نیاز نباشد؛ بنابراین ممکن است اعلان با کمی تأخیر نسبت به دقیقه دقیق نمایش داده شود.
- داده‌ها در localStorage وب‌ویو روی همان دستگاه ذخیره می‌شوند. پیش از پاک‌کردن داده‌های برنامه، از بخش پشتیبان‌گیری خروجی بگیر.
- نسخه اولیه باید روی دستگاه واقعی آزمایش شود؛ در این محیط امکان اجرای Flutter/Gradle و تولید APK باینری وجود نداشت.

نکته ساخت ابری: workflow ابتدا فایل‌های پلتفرم اندروید/Gradle را با Flutter stable تکمیل می‌کند، سپس APK release می‌سازد.
