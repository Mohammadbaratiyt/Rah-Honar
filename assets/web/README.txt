راهِ هنر - نسخه ۲
دستیار مطالعه کنکور هنر ۱۴۰۶

محتویات بسته:
- index.html: برنامه اصلی
- data/books.json: فهرست ۱۹ منبع هدف و فصل‌های استخراج‌شده از PDFهای موجود
- assets/fonts: فونت Kalameh با وزن‌های Thin، Regular، Bold و Black
- manifest.webmanifest و sw.js: نصب‌پذیری و کش آفلاین PWA
- icons: آیکون‌های نصب

منابع:
از ۴ پارت PDF ارسالی، ۱۷ کتابِ مرتبط با فهرست ۱۹ منبع شناسایی شد. فایل «تصویربرداری و صدابرداری برنامه‌های تلویزیونی» عمداً وارد برنامه نشده است. دو عنوان «درسنامه جامع ریاضی و فیزیک هنر» و «تخصصی معماری داخلی» در ZIPهای فعلی PDF نداشتند و به‌صورت نیازمند PDF علامت خورده‌اند. فایل «دانش فنی پایه معماری داخلی» برای «پایه معماری» استفاده شده است.

امکانات نسخه ۲:
- رابط فارسی RTL با تم آبی تیره، پوسته روشن و فونت Kalameh
- صفحه اول با پل نیمه‌خودکار ChatGPT: کپی درخواست و واردکردن JSON پاسخ
- برنامه فصل‌محور با حفظ ساعت‌های ثابت مطالعه و تقسیم محدوده صفحه‌ها
- ثبت تکمیل فصل، مرور فاصله‌دار، فعالیت شخصی و فعالیت جبرانی
- فلش‌کارت‌های بازیابی فعال و خودسنجی کوتاه آفلاین
- امکان کپی درخواست تولید تست و فلش‌کارت محتوایی برای ChatGPT
- اعلان هنگام بازبودن برنامه و فعال بودن مجوز اعلان
- پشتیبان‌گیری و بازیابی JSON

محدودیت‌های صادقانه:
- این بسته PWA است، APK نهایی نیست. در محیط ساخت فعلی Android SDK/Gradle برای کامپایل APK در دسترس نبود.
- برای نصب استاندارد PWA باید روی HTTPS یا localhost اجرا شود؛ بازکردن مستقیم index.html به‌تنهایی Service Worker و نصب PWA را فعال نمی‌کند.
- پل ChatGPT بدون API و هاست، خودکار نیست: کاربر متن را به ChatGPT می‌فرستد و پاسخ JSON را وارد برنامه می‌کند.
- مدل زبانی محلی داخل برنامه اجرا نمی‌شود. فلش‌کارت‌ها و خودسنجی آفلاین این نسخه از نوع بازیابی فعال و پرسش‌های راهبردی هستند؛ برای سؤال‌های محتوایی، دکمه‌های ساخت تست/فلش‌کارت با ChatGPT درخواست فصل را آماده می‌کنند.
- اعلان‌های PWA در این نسخه فقط هنگام بازبودن برنامه بررسی می‌شوند؛ اعلان قابل اتکا در حالت بسته به پیاده‌سازی بومی APK نیاز دارد.
- شماره صفحات، شماره چاپی درج‌شده در فهرست کتاب‌هاست. برای برخی کتاب‌های پودمانی که فهرستشان شماره شروع فصل را به شکل یکپارچه نشان نمی‌دهد، عنوان پودمان ثبت شده و محدوده صفحه به‌صورت حدسی ساخته نشده است.

شروع:
فایل ZIP را استخراج کن و پوشه را روی یک وب‌سرور HTTPS قرار بده. سپس در مرورگر Android باز کن و از منوی مرورگر گزینه Install app / Add to Home screen را انتخاب کن.
برای انتقال دستگاه یا جلوگیری از حذف اطلاعات، از تنظیمات برنامه خروجی JSON بگیر.
